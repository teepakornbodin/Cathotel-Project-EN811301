# 🐱 Cat Hotel Management System

A web-based cat hotel management platform designed to help cat owners monitor their pets in real time while enabling hotel administrators to efficiently manage bookings and cat status updates.

---

## 📌 Overview

Cat owners often struggle to find trustworthy boarding services for their pets.

One major concern is the lack of clear communication and real-time updates while their cats are staying at the hotel.

The **Cat Hotel Management System** was developed to solve this problem by providing:

- Cat room booking
- Real-time cat status updates
- Reservation management
- Transparent communication between owners and administrators

---

## 🎯 Project Motivation

Many cat owners have limited time to care for their pets and need reliable cat hotel services.

Without proper updates, owners may worry whether their cats are:

- Safe
- Healthy
- Properly cared for

This platform provides peace of mind through status tracking and management tools.

## ⚙️ System Workflow

### 1. User Registration / Access
Users enter the platform.

### 2. Room Booking
Select available room and submit reservation.

### 3. Admin Processing
Admin reviews booking and creates cat profile.

### 4. Status Updates
Admin updates cat condition in system.

### 5. Owner Monitoring
Owners can check cat status anytime.

### Problem 2

**Solution:**

### Problem 3
Cat information not displaying

**Solution:**
